# EcommerceShop - ASP.NET Core MVC Project

## Giới thiệu

EcommerceShop là dự án website bán hàng được xây dựng nhằm mục đích thực hành và nâng cao kỹ năng lập trình với ASP.NET Core MVC và các công nghệ liên quan.


# Công nghệ sử dụng

## Backend
- ASP.NET Core MVC
- Entity Framework Core
- MSSQL Server
- LINQ
- ASP.NET Identity
- Session & Authentication

## Frontend
- Bootstrap 5
- JavaScript / JQuery
- DataTables
- Quill Editor
- SweetAlert2

## Khác
- Git & GitHub
- MVC Pattern
- VNPay Sandbox

---

# Tính năng

- Đăng ký / Đăng nhập / Phân quyền người dùng
- Xem danh sách và chi tiết sản phẩm
- Thêm, cập nhật, xoá sản phẩm trong giỏ hàng
- Đặt hàng và quản lý đơn hàng
- Thanh toán COD và tích hợp VNPay
- Upload ảnh chính và nhiều ảnh phụ cho sản phẩm
- CRUD sản phẩm, danh mục và thương hiệu trong Admin Dashboard
- Quản lý người dùng và Role
- API trả dữ liệu JSON cho DataTables
